12 /-!
13 # Typed assembly interfaces for the paper proof
14 
15 This module packages three application interfaces used by the canonical Weyl
16 construction. The first two include the characteristic-support and symbol
17 dictionaries; the third supplies a retained boundary place with a visible
18 divisor frame on each nonconstant component.
19 
20 `Stafford38.FoundationClosure` proves every field and imports this module on
21 the ordinary root dependency path. No field is installed as an axiom or
22 typeclass. The assembly theorems here remain conditional when considered in
23 isolation; their hypotheses are discharged by the unconditional development.
24 -/

43 /-- Exact Stafford-specific output of the noncharacteristic inverse-image
44 application.  This is support avoidance, not the stronger filtered predecessor
45 to which it is converted by a separate trust-zero algebraic theorem. -/
46 def CanonicalNoncharacteristicSupportAvoidance : Prop :=
47   ∀ (k : Type u) [Field k] [CharZero k] [IsAlgClosed k] (n N : ℕ)
48     (d : WeylAlg k (n + 1)),
49     0 < N → IsPBWMonicAt k (.inr (0 : Fin (n + 1))) N d →
50       Disjoint
51         (transposedOrderAssociatedGradedSupport k
52           (canonicalRightIdeal (presentedCoordinate k n) d N))
53         (PrimeSpectrum.zeroLocus
54           ({MvPolynomial.X (.inl (0 : Fin (n + 1)))} :
55             Set (SymbolRing k (n + 1))))
